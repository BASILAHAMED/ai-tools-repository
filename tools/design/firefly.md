# Adobe Firefly

**Developer:** Adobe  
**Category:** Design & Visual  
**Website:** https://firefly.adobe.com  
**Pricing:** Freemium - Free, Plus ($19.99/mo), Team ($37.99/user/mo)

---

## 📋 Overview

Adobe Firefly is Adobe's AI-powered creative suite integrated directly into Creative Cloud applications. Unlike standalone AI image generators, Firefly is designed to work seamlessly with Photoshop, Illustrator, and other Adobe tools. It focuses on commercially safe, ethically trained AI with deep integration into professional creative workflows.

## ✨ Key Features

- **Text to Image** - Generate images from text prompts
- **Generative Fill** - Add, remove, or expand content in images
- **Text Effects** - Apply styles to text
- **Generative Recolor** - Recolor vector artwork
- **3D to Image** - Generate images from 3D compositions
- **Photoshop Integration** - Direct access in Photoshop
- **Illustrator Integration** - AI-powered vector tools
- **Express Integration** - Quick design creation
- **Commercial Safe** - Trained on licensed and public domain content
- **Brand Safe** - No copyright concerns for commercial use

## 🔧 Technical Details

- **Platform:** Web, Photoshop, Illustrator, Express
- **AI Model:** Proprietary diffusion models
- **Training:** Licensed, public domain, and out-of-copyright content
- **Credits:** Generative credits system (monthly allocation)
- **Resolution:** Up to 2K
- **Commercial Use:** Allowed with appropriate plan
