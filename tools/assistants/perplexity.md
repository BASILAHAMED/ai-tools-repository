## 📋 Overview

Perplexity AI is a research-focused AI assistant that combines conversational AI with real-time web search and comprehensive citations. Unlike traditional chatbots, Perplexity provides synthesized answers with source attribution, making it ideal for research, fact-finding, and academic work. It uses advanced retrieval-augmented generation (RAG) to ensure accurate, up-to-date information.

## ✨ Key Features

- **Real-time Web Search** - Access current information with every query
- **Citations & Sources** - Every answer includes verifiable sources
- **Academic Research Mode** - Focus on peer-reviewed sources
- **Thread-based Conversations** - Organized, topic-based discussions
- **File Upload** - Analyze PDFs, text files, and images
- **Collection Organization** - Save and organize research
- **API Access** - Integrate Perplexity's search capabilities
- **Focus Modes** - Academic, writing, YouTube, Reddit, etc.
- **Copilot Mode** - Interactive, guided research assistance
