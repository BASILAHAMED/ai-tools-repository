## 📋 Overview

Cursor is an AI-native IDE built from the ground up around AI assistance. Unlike traditional IDEs with AI plugins, Cursor integrates AI deeply into every aspect of the development workflow. It's designed specifically for AI pair programming, offering natural language commands, codebase-aware suggestions, and multi-file editing capabilities. Built on VS Code, it provides a familiar environment with revolutionary AI features.

## ✨ Key Features

- **AI-First Architecture** - Built from ground up for AI collaboration
- **Natural Language Commands** - Describe changes in plain English
- **Codebase Awareness** - Understands entire project context
- **Multi-file Editing** - Make changes across multiple files simultaneously
- **Chat Interface** - Conversational coding within the IDE
- **Auto-commit Generation** - AI-powered commit messages
- **Diff Previews** - See proposed changes before applying
- **VS Code Compatible** - Familiar interface with extensions support
- **Cursor Agent** - Autonomous agent for complex tasks
- **Codebase Indexing** - Fast semantic search across your code

## 📚 Pro Tips

- Use **Cmd/Ctrl+K** to open the command interface
- Describe changes in **natural language** for best results
- Use **@mentions** to reference specific files or functions
- Leverage **multi-file edits** for refactoring
- Review **diffs** before applying AI suggestions
- Create **custom rules** for your codebase
- Use the **chat** for explanations and debugging
- Enable **auto-imports** for faster coding
