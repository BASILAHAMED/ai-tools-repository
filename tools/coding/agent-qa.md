## 📋 Overview

Agent QA uses YAML test files with natural-language steps for web, Android and iOS application testing. Tests can be authored and run through a CLI, local dashboard or local MCP server.

## ✨ Key Features

- YAML files describe application-test scenarios with natural-language steps.
- Web, Android and iOS are supported test targets.
- CLI and local dashboard interfaces manage the testing workflow.
- Local MCP tools support authoring, validating, running and triaging tests.

## 💰 Pricing and License

The software is currently free under **FSL-1.1-ALv2**. Configured model, browser and device services may charge separately; their availability and costs depend on the services selected.

## ⚠️ Requirements and Limits

- The published `agent-qa` package declares **Node.js ≥24**.
- Local MCP execution requires a configured local dashboard/dashboardUrl.
- Browser, mobile-device and model connections require the corresponding setup.
