## 📋 Overview

Tableau AI (formerly Einstein AI) brings artificial intelligence capabilities to Tableau's leading data visualization platform. It enables users to explore data, generate insights, and create visualizations using natural language queries. With automatic dashboard generation, trend prediction, and AI-assisted data preparation, Tableau AI democratizes data analytics for business users without requiring technical data science skills.

## ✨ Key Features

- **Ask Data** - Natural language queries to explore data
- **Automatic Dashboard Generation** - AI creates dashboards from questions
- **AI-Powered Predictions** - Forecast trends and outcomes
- **Data Preparation** - Automated data cleaning and transformation
- **Explain Data** - AI explains why patterns exist in data
- **Smart Recommendations** - Suggest relevant visualizations
- **Pre-built Models** - No-code machine learning
- **Integration with Salesforce** - Deep CRM data integration
- **Collaboration** - Share insights and dashboards
- **Mobile Access** - Access analytics on the go
